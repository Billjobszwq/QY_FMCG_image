## 3. 货架场景数据多样性矩阵（关键）

货架巡检的难点在于现场条件多变。数据采集/盘点/增强必须显式覆盖以下维度，避免模型只在"好照片"上达标：

| 维度 | 需覆盖的典型取值 | 采集/盘点要点 |
|---|---|---|
| **光照** | 门店射灯、自然日光、阴影、混合光、逆光 | 同一货架尽量有多种光照样本 |
| **拍摄角度** | 正对、俯视、斜视（≤ 约 45°） | 非正对样本不可缺失 |
| **距离/尺度** | 远景整架、近景单品 | 覆盖不同商品框尺度 |
| **遮挡** | 价签遮挡、商品互挡、手/人体局部遮挡 | 必须有遮挡样本（支撑"不可判定"出口） |
| **密集度** | 稀疏陈列、密集陈列、缺货空位 | 密集货架考验检测召回 |
| **包装状态** | 正面、侧面、倒置、皱缩/破损 | 侧面/倒置样本支撑鲁棒性 |
| **新旧包装** | 在售新版、库存旧版 | 每个高相似 SKU 两版都要有 |

> 评测（T11）必须按以上维度**分组输出指标**。某切片 Top-1 低于整体 15 个百分点以上，视为该切片数据/能力不足，需定向增强（见 R-03）。

## 4. 金标准集构建（500 张）

金标准是全系统的验收标尺，必须最严格地保护。

### 4.1 构建规则

1. **来源独立**：从现场图中选取，**不得**用标准商品图、不得用模型预测生成。
2. **人工独立标注**：由标注员独立完成，标注时**不展示模型预测**，避免锚定偏差。
3. **覆盖代表性**：按 §3 多样性矩阵分层抽样，确保各光照/角度/遮挡/各 SKU 都有代表；高相似 SKU 组适当超采。
4. **包含困难样本**：故意纳入未知 SKU、不可判定、候选冲突、遮挡样本，以检验三种非强制出口。
5. **冻结与授权**：金标准集一旦冻结即独立授权管理；任何训练/调参/阈值选择不得读取金标准标签（技术上隔离存储 + 权限控制）。

### 4.2 标注一致性（质量门）

| 项 | 要求 |
|---|---|
| 交叉标注 | 金标准中至少 10%（50 张）由 2 名标注员独立标注 |
| 一致性阈值 | SKU 级标注 **Kappa ≥ 0.8**；商品框 IoU ≥ 0.7 |
| 歧义裁决 | 不一致样本由标注负责人依《标注规范》裁决，裁决记录留痕 |
| 规范先行 | 标注前发布 `annotation-guide.md`，含高相似 SKU 判别要点与边界案例 |

> Kappa < 0.8 → 说明规范不清或 SKU 本身难分，需修订规范或调整 SKU 清单，**不得强行推进**（对应 R-09）。

### 4.3 标注内容

每张金标准图标注：商品框（矩形）、SKU 编码、或三种出口之一（未知 SKU / 不可判定 / 候选冲突）、必要时的冲突原因。标注规范细化技术计划 Task 1 Step 1 的要求。

## 5. 数据集切分与防泄漏

### 5.1 切分原则

- **仅用人工确认/批准的标签**进入训练/验证集；自动预测永不入库为标签。
- **按组切分**：以拍摄批次、门店或来源为分组键切分训练/验证，**同一组不跨集**。
- **近重复去重**：内容哈希 + 感知哈希去重；连续拍摄（连拍/同场景微移）归入同一组。

### 5.2 零泄漏验证（T9 测试必须覆盖）

| 泄漏类型 | 验证方法 |
|---|---|
| 原图泄漏 | 训练集与验证/金标准的图片内容哈希无交集 |
| 近重复泄漏 | 感知哈希近似图不跨集 |
| 批次泄漏 | 同一连续拍摄批次不跨训练/验证 |
| 金标准泄漏 | 金标准 ID **绝不**出现在训练清单 |

> 泄漏测试失败即阻止该 dataset_version 发布（对应 R-12）。

## 6. 定向补拍与增强计划（按需触发）

若盘点（§2）发现缺口，执行定向补拍而非盲目扩量：

1. **补拍对象优先级**：① 现场图不足的高相似 SKU；② 多样性矩阵中的弱势条件（如遮挡、逆光、侧面）；③ 新旧包装中缺失的一版。
2. **补拍规范**：固定记录设备、距离、光照条件，便于分组评测；补拍图同样进入盘点与标注流程。
3. **增强仅作辅助**：几何/光照增强可用于训练扩容，但**不得**用于金标准，也不得替代真实现场样本的多样性。

## 7. SKU 知识库数据质量（对接 Task 4）

知识库质量直接决定硬过滤与召回，商品知识负责人需保证：

| 字段 | 要求 |
|---|---|
| SKU 编码、标准名称、品牌 | 必填、唯一 |
| 规格、口味、容量 | 必填（高相似 SKU 的判别关键） |
| 包装版本 + 生效日期 | 明确，避免版本重叠歧义 |
| 条形码 | 必填且无冲突；冲突须阻止知识版本发布 |
| 别名 | 覆盖常见叫法，辅助 OCR 匹配 |
| 参考图 | 每 SKU 至少正面标准图，生成 SigLIP2/DINOv2 向量入 pgvector |
| 硬冲突字段 | 显式存储，供 T6 硬过滤使用 |

校验器（T4）必须在知识版本发布前拦截：条码冲突、规格缺失、包装版本重叠、孤立图片。

## 8. 数据治理与安全

- **权限分级**：金标准集、训练集、知识库分别授权；金标准标签读取需独立审批。
- **追加式反馈**：人工纠错以新 `review_event` 追加，禁止改写历史（技术计划 Task 3）。
- **保留与合规**：图片与标注的保留期限、访问审计由安全/法务确定（对应 R-15）；图像本地存储不出内网。
- **版本化**：每次数据集快照生成不可变 `dataset_version`，记录来源、切分、标签来源。
