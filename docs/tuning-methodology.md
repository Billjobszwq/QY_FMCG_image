# 模型迭代调优方法论

> 本文记录 SKU 检测模型「先评估诊断，后针对性调优」的迭代方法论与各轮训练演进。每轮训练都遵循同一闭环，而非盲训。

## 核心方法论：评估→诊断→定向调优

每一轮训练**不盲训**，严格按以下闭环迭代：

```
基准推理 → 差异挖掘 → 痛点诊断 → 定向调参 → 训练 → (早停) → 交付对比
   ↑_______________________________________________________________|
                          新一轮基准（用上一轮 best.pt）
```

### 第一步：基准推理与差异挖掘

用上一轮最佳权重（best.pt）对当前数据集全量推理，与 Ground Truth（SKU 标签 + 坐标框）逐一比对，输出：

- **漏检列表**：GT 有、模型未检出（点未被任何预测框覆盖）
- **误检列表**：GT 无、模型错误检出（预测框未覆盖任何 GT 点）
- **分类错误列表**：框对了但 SKU 判错（最需关注）
- **混淆矩阵**：哪些 SKU 之间高频互判

比对采用「GT 点落在预测框内」匹配；验证集**仅取新增照片**（不与历史训练集交叉），从根本上防止数据泄露导致指标虚高。

### 第二步：痛点诊断 → 调参规则

依据差异报告的核心痛点，按以下筛查规则定制调参：

| 诊断痛点 | 调参策略 |
|---|---|
| 同类商品不同规格误判（细粒度混淆） | 提升 cls_loss 权重（1.0→1.2）；降低学习率 |
| 漏检严重（召回率低） | 降低置信度阈值；增强 Mosaic/MixUp/scale/copy_paste |
| 过拟合趋势（val-train 差距扩大） | 降 lr0；余弦退火；增 dropout/weight_decay；强制早停 |
| 精确率 < 召回率（模型过"大胆"） | 提升 cls 权重压误检；增正则化 |
| 旧数据表现良好 | 从 best.pt 渐进微调（非随机初始化） |

### 第三步：训练与强制早停

- **强制早停**：`patience=10`。连续 10 轮验证集 mAP50 无法刷新历史最佳，立即终止，**绝不无脑跑满预设轮数**。
- **学习率调度**：warmup 3 轮预热避免梯度震荡 → 余弦退火（`cos_lr=True`）帮助跳出局部最优。
- **数据增强**：按痛点动态调整 Mosaic/MixUp/scale/copy_paste 强度；`close_mosaic` 控制最后 N 轮关闭 Mosaic。

### 第四步：交付物

每轮交付：① 差异报告（漏检/误检/分类错误占比）② 新 best.pt + 训练曲线 + 最终 mAP50 ③ 混淆矩阵（标注 Top3 最易混淆 SKU 对）。

## 训练轮次演进

| 轮次 | 数据集 | 关键参数 | 最佳 mAP50 | 关键改进 |
|---|---|---|---|---|
| sku_v1 | 第一批 2947 | yolo26m, imgsz640, cls0.5 | 0.405 | 基线（统一框尺寸）|
| sku_v2 | 第一批 | imgsz960, cls0.8 | 0.338* | 中间轮（被 v3 取代）|
| sku_v3 | 第一批 | imgsz960, cls0.8, **SKU自适应框** | 0.439 | 修复统一框尺寸→召回提升 |
| sku_v4 | 第二批新旧混合 5976 | 微调自v3, cls1.0, lr0.0005, mixup0.25 | **0.6887** | 大数据+微调，召回 32%→58% |
| sku_v5 | 第二批新旧混合 5976 | 微调自v4, cls1.2, cos_lr, dropout0.15, wd0.001, patience10 | 历史轮次，已结束 | 抗过拟合+细粒度分类 |

\* sku_v2 因 SKU 自适应框修复在 v3 落地后被取代。

### 关键经验

1. **SKU 自适应框尺寸**（v3）：点标注转框时按商品形态（大瓶/标准瓶/罐装/小瓶）赋予不同框比例，而非统一 7%×18%，是检测召回提升的关键数据修复。
2. **新旧混合 + 渐进微调**（v4）：第二批数据几乎包含第一批（2945 张交叉），从 best.pt 微调而非随机初始化，mAP50 从 0.439 跃升至 0.6887。
3. **防泄露验证集**：验证集仅从新增照片抽样，确保指标反映真实泛化能力。
4. **细粒度混淆是持久瓶颈**：佳得乐 橙/柠檬/蓝莓、1L百事↔可口可乐2L 等同品类不同规格 SKU 互判，需持续提升 cls 权重与数据增强。

## 当前最优模型

- **权重**：`.models/sku_v4/weights/best.pt`（Epoch 35，mAP50=0.6887，P=0.613，R=0.676）
- **Top3 最易混淆 SKU 对**：① 佳得乐柠檬↔蓝莓 ② 佳得乐橙↔蓝莓 ③ 1L百事↔可口可乐2L
- **第五轮（sku_v5）**：基于 v4 痛点（过拟合趋势 + 精确率<召回 + 细粒度瓶颈）定向调优；该轮现已结束，当前训练已停止。
