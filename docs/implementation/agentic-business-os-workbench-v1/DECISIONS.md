# Decisions

- `D-001` 产品唯一定位为 Graph+Loop Agentic Business OS；识别是首个 Domain Pack。
- `D-002` 采用“统一平台壳层 + Manifest 驱动 + 识别纵向切片”，不做纯换皮或全量重写。
- `D-003` 模块色仅作 accent，状态色独立；操作后台不照搬营销型第三方页面。
- `D-004` 一级/二级/三级必须是 Registry、真实 route、结构化 action。
- `D-005` Supervisor 默认总入口；领域 Agent 独立权限、工具、记忆和审计。
- `D-006` 现有 production 通过 adapter 保留；本轮不训练、不切生产。
- `D-007` 未来模块可以 planned，但不得用识别数据或静态卡片伪装已完成。
