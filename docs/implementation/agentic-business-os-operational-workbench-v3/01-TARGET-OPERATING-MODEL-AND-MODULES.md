# 目标运营模型与模块工作台

## 1. 全局信息架构

一级导航只表达用户业务域，不表达内部技术组件：

1. 首页
2. 数据与资产
3. 调研与问卷
4. 位置与外勤
5. 智能识别
6. 分析与 BI
7. 工作流与 Agent
8. 账号与权限
9. 客户与主数据
10. 财务与用量
11. 帮助与文档
12. 系统管理（仅管理员）

每个一级模块使用稳定色系；二级导航表达功能区；三级操作在页面工具栏、详情抽屉或向导中完成。禁止透明占位按钮、不可点击卡片、假图表和把 JSON 当主要业务界面。

## 2. 首页与主管工作台

### 首页 Dashboard

首页不是欢迎页，必须由真实 API 组成：

- 今日待办：逾期、今天、本周、等待人工、被阻断；
- 日历：任务截止、外勤计划、问卷周期、训练计划、报表计划和用户日程；
- 项目进度：按客户/项目显示完成率、当前节点、风险和负责人；
- 实时活动：来自 Event/Audit 的业务活动，不展示原始噪声日志；
- 系统容量：数据库、对象/照片、磁盘、内存、队列、模型驻留和服务健康；
- Agent 提醒：需要批准、需要补数据、异常和建议；
- 快速目标：服务端保存，确认后形成 Goal→Plan→WorkItem，不得刷新丢失；
- 最近对象：客户、项目、问卷、工作流、Dashboard 和识别任务。

每张卡点击后必须打开同一对象详情，不能跳到没有上下文的模块首页。

### 主管工作台

- 桌面端为右侧可折叠、可调宽的 360–480px 工作区，不覆盖主内容；
- 1024 以下改为可关闭底部工作区；768 以下为全屏对话页；
- 主管可引用当前页面对象，也可全局查询；
- 输出分为“回答、证据、建议操作、待批准命令、委派、记忆更新”；
- 命令先预览影响、成本、权限、回滚，再由用户批准；
- Agent 不可用时，明确显示原因和人工入口；
- 会话、消息、引用、命令和结果服务端持久化。

## 3. 数据与资产

定位为“系统数据与资源运营中心”，不是空资产表：

- 数据总览：客户、项目、用户、SKU、门店、地址、照片、问卷、响应、任务、报表、模型、证据和 Usage 数量；
- 容量总览：数据库大小、8T 本地盘已用/可用、目录占用、增长趋势、保留期预测；
- 运行资源：CPU/GPU/MPS、内存、swap、模型驻留、队列、训练/推理租约；
- 数据质量：缺字段、重复、无法解码、无坐标、无客户归属、孤儿记录和泄漏风险；
- 资产浏览：按客户/项目/类型/时间/状态检索和下钻；
- 数据血缘：导入批次→主数据→任务→照片→识别→问卷→BI→Usage/结算；
- Import Center：模板下载、上传、字段映射、dry-run、错误修复、提交、批次回滚/补偿；
- 保留策略：只展示和模拟，删除/归档必须单独批准。

## 4. 调研与问卷

### 二级功能

- 问卷设计器
- 模板库
- 发布与版本
- 分配与周期
- 填写/预览
- 响应数据
- 评分与质检
- 照片与识别建议

### 问卷设计器

用户可以从空白创建，不依赖样板：

- 左侧题型库：SKU 库、客户库、项目库、单选、多选、填空、数字、日期、打分、矩阵、说明、拍照；
- 中间画布：拖拽新增、排序、复制、分组、分页、删除；
- 右侧属性：标题、编码、必填、选项、默认值、校验、分值、维度、数据绑定、可见条件；
- 跳题逻辑：可视化条件与目标题，发布前检测环路和不可达题；
- 自动评分：题目分、维度分、权重、阈值、合格/异常规则；
- 照片题：照片类型、数量、门头/自拍必选、质量门、识别 profile、识别结果映射；
- 预览：桌面/移动端，测试答案不进入正式响应；
- 版本：草稿可编辑，发布版不可原地修改，新版本保留映射和迁移说明。

模型输出只能作为 suggestion；人工确认后才进入 final answer 和正式报表。

## 5. 位置与外勤

### 地址与坐标

- 地址库可单条新增和 CSV/XLSX 导入；
- 字段包含客户、项目、门店、标准地址、区域、联系人、营业时间、经纬度、坐标系、来源、置信度；
- “获取坐标”支持选中地址、导入批次和全部缺失地址；
- 地理编码结果显示候选、置信度和证据；低置信必须人工选择；
- 支持用户手工在地图移动点位并追加修正记录。

### 规划与地图

- 员工、技能、班次、起终点、交通方式、服务时长、费用和任务容量可配置；
- 路线规则支持区域、客户优先级、时间窗、距离、差旅预算、同项目/多项目合并；
- 提供地图画区、地图选店、路线展示、未分配任务和冲突解释；
- 电子围栏包含到店/离店、允许误差、弱 GPS 处置和证据；
- 门头照为任务必选，员工自拍保留可配置口子；
- 无门店清单的普查任务支持地图网格、主管协调和 Agent 建议分区，最终派发可人工调整。

首版允许启发式路线作为 fallback，但必须明确算法、约束违反和未优化原因；不能把最近邻称为完整 VRP 最优解。

## 6. 智能识别与自主训练

### 识别工作台

- 单图、批量、URL、API、Agent 五入口共用同一任务台账；
- 默认 Profile 切换为经验证的 `best/sku_v4_best.pt`；
- 模型选择显示：用途、版本、artifact hash、状态、精度口径、延迟、资源、适用范围和 blocker；
- 不可用模型不可选择，但必须提供“诊断/准备上线”入口；
- 其他现有 detector/segmenter/classifier/VLM 以 experimental profile 本机上线，经真实加载测试后可手动选择；
- 结果展示原图、框/mask、SKU、置信度、模型路径、耗时、费用、证据和人工修正入口。

### 标注与数据集

- Label Studio 是正式标注入口，Web 中有清楚的打开、项目、任务、同步、标签检查和回填入口；
- assisted 显示模型建议，blind 不得泄漏 prediction；
- 数据集页面可以选择照片池、筛选规则、去重、质量门、标注状态、客户/项目、split 规则；
- Snapshot 不可覆盖，显示 manifest、hash、数量、类分布、泄漏审计和来源。

### 自主训练中心

至少支持 detector、YOLO-seg、classifier、VLM 四条 Lane：

- 选择数据集快照和基础模型；
- 参数表单、预设、资源估算、Apple/MPS/MLX preflight；
- dry-run→批准→排队→运行→暂停/安全停止→完成/失败；
- 实时日志、epoch/step、loss、指标、内存、swap、耗时和预计完成；
- 制品、hash、训练元数据、独立评估、候选比较和发布计划；
- MLX 重任务独占；其他 heavy 默认并发 1，只有实测吞吐收益后才并发；
- 页面必须解释“训练完成、候选、评估通过、生产上线”是四个不同状态。

本轮不授权新的长时间训练；允许 smoke/preflight 和现有制品运行时加载验证。

## 7. 分析与 BI

### 数据与语义

- 注册数据集/数据产品，显示字段、类型、客户范围、刷新时间和血缘；
- 指标设计器定义聚合、过滤、时间窗、维度、单位和业务解释；
- 计算字段使用受限公式 DSL，禁止任意 SQL；
- 提供数据预览、公式测试、空值/除零/类型错误提示。

### Dashboard 与报告

- 可视化图表库、画布、布局、筛选器、维度钻取、联动和保存；
- 报告可以按客户、项目、区域、员工、SKU、时间等维度拆分；
- v1/v2 版本分别显示、比较和回滚，禁止列表重复 latest；
- Analytics Agent 根据自然语言生成指标/图表/报告 draft，展示数据源和计算逻辑后人工发布；
- 异常可以追问、分派调查、记录回答、评价解释并刷新报告；
- 数据追踪显示每个数字来自哪些响应、识别任务和导入批次。

建议使用 Apache ECharts 等宽松许可证图表库；不得以静态假图代替真实查询结果。

## 8. 工作流与 Agent

工作流要求见 `02-WORKFLOW-AGENT-RUNTIME-DECISION.md`。本模块至少包含：

- 可视化工作流画布、模板、版本、测试、发布、运行、批准、失败和证据；
- Agent 中心、Agent 配置、Prompt、Skill、知识库、工具、记忆、预算、测试和日志；
- 模型/Provider 连接设置；
- 所有节点、Agent 和模型都从 Registry 投影，不手写第二份列表。

## 9. 账号与权限

- 用户、服务账号、角色、权限、数据范围、审批矩阵、会话和审计；
- 用户可新建角色、复制角色、勾选模块/动作/客户/项目范围；
- 权限模拟器回答“某用户能否对某客户执行某动作”及原因；
- 多角色取权限并集但明确拒绝优先；多客户授权不得只取第一个；
- 禁止删除/停用最后一个 owner/platform_admin；
- 高风险权限变更需要二次确认和审计；
- 批量用户/角色/成员关系支持模板导入。

## 10. 客户与主数据

- 客户、项目、SKU、包装版本、门店、员工、地址、区域和业务标签；
- 每个对象支持 CRUD、停用、搜索、批量导入、批量导出、合并建议、重复检测和变更历史；
- SKU 新包装可以沿用旧名称或新名称，由客户/项目策略决定；
- 客户和项目切换是全局上下文，但任何跨客户汇总都必须有明确权限；
- 不允许页面直接改数据库，全部走 Domain Service 和审计事件。

## 11. 财务与用量

本轮只做可核对 Usage 工作台：

- 按客户/项目/日期/来源查看照片存储、识别张数、模型计算、Agent/LLM Token、人工任务等日志；
- 每条 Usage 下钻到 run、task、evidence、模型和规则版本；
- 显示日/月趋势、预算、异常、未归属和导出；
- 费率卡可以维护草稿，但本轮不要求生成正式会计凭证；
- 已结算记录不可原地改写，调整使用追加记录。

## 12. 帮助、文档与系统管理

### 帮助与文档

- 新手教程、角色操作手册、模块 How-to、导入模板说明、API Reference、常见故障；
- 全文搜索、版本、更新时间、当前功能状态和复制命令；
- 主管 Agent 可以根据文档回答“怎么做”，并导航到对应页面。

### 系统管理/开发者

仅管理员可见：服务健康、模块注册、API Explorer、迁移、Feature Flags、Provider/Secret 状态、审计、限流和开发者诊断。不得把它放在普通业务用户的核心导航中。
