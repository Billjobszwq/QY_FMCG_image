## 2. 重点风险详述（HH / HM）

### R-01 现有图片"量大质不高"（HH）
- **描述**：已有大量图片 ≠ 有 500 张独立、清晰、带准确人工标签的金标准。可能存在模糊、角度单一、标签缺失、近重复。
- **触发条件/预警**：数据盘点（见数据专项计划 §2）显示可用清晰图 < 1500 张，或金标准候选 < 500 张，或近重复率 > 20%。
- **应对（缓解）**：M0 即做数据盘点；把"金标准构建"单列为数据专项，不混入采集；不足部分定向补拍（针对弱势 SKU/光照）。
- **关联**：T1、T9；数据专项计划。

### R-02 小团队 CV/MLOps 瓶颈（HH）
- **描述**：关键路径（T4→T6→T7→T11）高度依赖 CV 能力；若 1 人兼任 CV+MLOps，构成单点，任一人生病/离职即停摆。
- **触发条件/预警**：关键路径任务预计延期 > 1 周；CV 角色无备份。
- **应对（缓解/转移）**：① 关键路径文档化、结对评审降低 bus factor；② 识别可外包环节（标注、部分训练实验）；③ 立项时明确外部支援预算；④ 采用 WBS §5.1 的串行+砍 MVP 策略降低并行压力。
- **关联**：章程 §6；WBS §2、§5。

### R-03 货架场景数据多样性不足（HH）
- **描述**：门店光照（射灯/日光/阴影）、拍摄角度（非正对）、遮挡（价签/手/商品互挡）、密集货架是货架巡检的固有难点。若训练数据集中在理想条件，现场指标会大幅劣化。
- **触发条件/预警**：分组指标（按光照/角度/遮挡切片）中某切片 Top-1 显著低于整体（差 > 15 个百分点）。
- **应对（缓解）**：数据采集/盘点时刻意覆盖多样条件；评测必须按切片输出（T11）；对弱势切片定向增强。
- **关联**：T11；数据专项计划 §3。

### R-04 无人工基线（HM）
- **描述**："人工审核时间下降 30%/50%"无现状基线则无法验收，项目价值无法证明。
- **触发条件**：立项评审时 §1.1 基线仍为空。
- **应对（规避）**：立项前置硬条件 —— 用一个典型门店做计时与抽样测算，写入章程后方可开工。
- **关联**：章程 §1.1、§9。

### R-05 本地 VLM 不达标（HM）
- **描述**：Qwen2.5-VL 在高相似 SKU 上可能判别力不足、幻觉、结构化输出不稳、本地推理延迟高。
- **触发条件/预警**：金标准上 VLM 裁决 Top-1 低于硬规则+检索基线；或非 JSON/非法输出率 > 5%；或单图延迟超业务可接受值。
- **应对（缓解）**：限制 VLM 输入为裁剪+结构化证据+Top-K 候选（降低幻觉面）；强制结构化 schema + 校验，非法即转人工；VLM 作为"裁决者"而非"唯一依据"，硬冲突规则优先；准备降级方案（纯检索+硬规则）。
- **关联**：T7、T11。

### R-06 未知 SKU 错误接纳率超标（HM）
- **描述**：把知识库中没有的新品/竞品强行匹配成已知 SKU，是货架场景高发错误，直接违反一票否决项。
- **触发条件/预警**：金标准未知错误接纳率 > 3%（技术验证）/ > 1%（试点）。
- **应对（缓解）**：设"未知"为一等出口；检索 Top-K 相似度设拒识阈值；条码/规格硬冲突直接转人工；评测单独统计该指标并一票否决。
- **关联**：T6、T7、T11。

### R-07 GPU/硬件预算未获批（HM）
- **描述**：本地 VLM 推理 + YOLO 训练需 GPU；预算未落实则 T7/T10 无法进行。
- **触发条件**：立项时硬件预算未批。
- **应对（规避）**：章程假设 A3 列为开工前置；M1 可先用较小模型/量化验证方案，降低首批硬件门槛。
- **关联**：章程 §8-A3；T7、T10。

### R-08 范围蔓延（HM）
- **描述**："通用 SKU"名称诱导业务方不断加 SKU/加场景/加功能（如陈列位置判定）。
- **触发条件**：出现未经范围闸门批准的 SKU/场景/功能扩张。
- **应对（规避）**：章程 §2.3 范围闸门 + §7 变更控制；任何扩张走联合审批。
- **关联**：章程 §2.3、§7。

### R-09 标注一致性不足 / 金标准污染（HM）
- **描述**：高相似 SKU 标注本身有歧义；多人标注不一致，或自动预测回流污染金标准，会使评测失真。
- **触发条件/预警**：交叉标注 Kappa < 0.8；或发现金标准含模型预测。
- **应对（缓解）**：标注规范 + 歧义裁决机制（见数据专项 §4）；金标准只用独立人工标签、独立授权、禁自动回流。
- **关联**：T9；数据专项计划 §4、§5。

### R-10 自研合法性未论证（HM）
- **描述**：若自研理由不成立，项目可能是在重复造可买的轮子，资源错配。
- **触发条件**：章程 §3 自研理由全部不成立。
- **应对（规避）**：立项硬闸门 —— 自研理由至少一条成立并记录；否则转商业方案 POC。
- **关联**：章程 §3。

## 4. 风险应对跟踪

- 每个 HH/HM 风险的负责人，每双周在迭代评审汇报：触发条件是否接近、应对措施是否落实。
- 风险升级规则：HM 风险概率或影响上升一档 → 升为 HH，进入项目负责人直管。
- 新风险随时登记，不等到评审会。
