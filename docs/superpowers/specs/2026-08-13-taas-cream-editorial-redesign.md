# TaaS 米白底战略编辑式改版规格

## 目标

将现有 TaaS 三受众推广页从深色技术大屏风格，重构为适合投资人、生态合作伙伴和潜在客户阅读的米白底战略编辑式页面。改版必须提升新品类辨识度、内容层级、图表可读性与演示节奏，同时保持现有三受众切换、六章叙事和离线单文件能力。

## 品牌层级

页面信息优先级固定如下：

1. `TaaS｜词元即服务`
2. `AI 原生业务操作系统`
3. 面向当前受众的核心判断与价值主张
4. `Token as a Service`
5. QIYUN Logo

Logo 只承担品牌署名，不与 TaaS 主标题争夺注意力。中文为主，英文仅用于辅助识别和小型标签。

## 视觉方向

采用“战略编辑式”而非传统产品官网或技术驾驶舱风格。页面应呈现为一份可以直接用于路演的高级战略说明：大标题、强观点、克制配色、充分留白和清晰证据图。

### 色彩系统

- 画布米白：`#F3EFE5`
- 内容纸白：`#FBF8F1`
- 主文字深墨：`#171D24`
- 次级文字灰褐：`#69675F`
- 分隔线暖灰：`#D8D0C1`
- TaaS 词元紫：`#7200FF`
- 可信治理青：`#079C94`
- 人工决策金：`#C58A00`
- 决策强调红：`#D92B55`

大面积区域只使用米白、纸白和深墨色。品牌色用于传达流程语义，不铺成大面积渐变背景。

### 字体与层级

中文使用系统无衬线字体，强调清晰与现代，不引入网络字体。TaaS 主标题采用高字重与紧凑字距；正文使用正常字重和舒展行距；英文辅助标签采用较小字号和适度字距。

## 页面结构

### 顶栏

浅色半透明粘性顶栏。左侧为深色 Logo，右侧为三类受众切换。受众切换采用下划线或轻量底色表示当前状态，不使用厚重按钮容器。

### 首屏

桌面端使用非对称双栏：

- 左侧约三分之二：TaaS 品类名、系统定位、当前受众标题、解释文案。
- 右侧约三分之一：一句战略判断，使用细竖线建立编辑式引用感。
- 下方横跨两栏：目标到结果的简化闭环，不再使用复杂曲线图作为首屏主体。

首屏首先让读者回答三个问题：这是什么、为什么是新品类、它带来什么结果。

### 闭环轨道

保留七阶段逻辑：

1. 业务目标
2. 可执行意图
3. 词元驱动理解与决策
4. 组织人员、数据与能力
5. 持续执行与人工守门
6. 可验证业务结果
7. 反馈、评估与能力进化

桌面端使用横向轨道；移动端使用纵向轨道。结果节点采用双线强调，反馈线明确返回业务目标。轨道背景与页面一致，不使用深色独立面板。

### 章节

六章统一为“观点—解释—证据图”结构：

- 左侧：章节序号、标题、论点、三条价值说明和承上启下语句。
- 右侧：与当前章节对应的业务图。

章节之间用留白和细线分隔。章节视觉不再使用大面积深色卡片；图表置于纸白区域，以层级、线条和少量语义色区分节点。

### 图表语言

- 所有节点使用浅色底和深色文字。
- 减少不必要的边框、切角和装饰内框。
- 每张图只保留一个主要阅读方向。
- 箭头必须表达真实的流程关系。
- 紫色表示词元驱动，青色表示治理与可信，金色表示人工守门，双线表示可验证结果。
- 图表标签中文优先，英文只出现在必要的辅助标题中。

### 导航与演示模式

章节导航使用轻量文本标签和细线状态。浏览模式保留完整长页；演示模式每次只显示一个章节，并在切换时将视口复位到内容顶部。交互必须支持键盘焦点和减少动态效果偏好。

## 响应式规则

- 1024px 以下：首屏与章节双栏比例收紧，图表保持可读。
- 820px 以下：章节改为单列，文案在前、图表在后；闭环轨道改为纵向。
- 520px 以下：首屏完全单列，战略判断位于主文案之后；顶栏与受众切换允许换行；所有图表使用专用移动布局，不通过整体缩放实现适配。
- 所有视口禁止横向溢出。

## 内容与技术边界

- 不暴露模型、提示词、编排算法、内部数据结构或底层工程实现。
- 只描述业务目标、词元驱动、组织能力、可信治理、人工守门、结果验证与持续进化。
- 保持单个 HTML 文件，Logo 使用内嵌数据 URI，运行时不得加载外部资源。
- 保留三类受众和六章内容数据结构，便于后续用户自行修改文案。

## 验收标准

- 页面背景为米白色，所有主要内容在浅色体系中可读。
- TaaS 是首屏最强视觉元素，Logo 明显但不抢占主叙事。
- 桌面端首屏符合战略编辑式双栏结构。
- 六章排版规则一致，图表不再呈现深色驾驶舱感。
- 三类受众切换、浏览/演示模式与章节导航正常。
- 1440、1024、768、390 像素宽度下无横向溢出。
- HTML 离线打开时无网络请求。
- 自动化契约测试与完整项目测试通过。
